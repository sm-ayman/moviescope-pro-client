# Moviescope Pro

[Live Site](https://moviescope-pro.netlify.app/)  

Moviescope Pro is a modern movie web application where users can explore, track, and manage movies. It provides a smooth, interactive experience for movie enthusiasts with features like top-rated movies, watchlists, and personalized collections.

---

## Features

- **Top Rated Movies:** Browse the highest-rated movies with ratings displayed prominently.  
- **Recently Added Movies:** Stay updated with the latest additions in the movie database.  
- **User Authentication:** Register, login, and login with Google to manage your watchlist and collections.  
- **Watchlist & My Collection:** Save your favorite movies or plan your watchlist for later.  
- **Dark & Light Mode:** Toggle between dark and light themes for a personalized viewing experience.
